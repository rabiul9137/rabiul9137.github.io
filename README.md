### 🎬 IMDB Movie Review Sentiment Analysis
An NLP project comparing traditional Machine Learning methods with BERT for classifying positive and negative movie reviews.

**Model results:**
- TF-IDF + Logistic Regression: 89.54% accuracy
- Word2Vec + Logistic Regression: 84.82% accuracy
- BERT: 90.78% accuracy and 91.01% F1-score
